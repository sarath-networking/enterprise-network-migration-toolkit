# Data Centre Networking Basics

## What is Data Centre Networking?
Data centre networking connects servers, storage, and infrastructure systems within enterprise and cloud environments.

## Common Goals
- High availability
- Scalability
- Redundancy
- Low latency
- Efficient traffic flow

## Spine-Leaf Architecture
Spine-leaf architecture provides predictable performance and scalable connectivity within modern data centres.

## East-West Traffic
East-west traffic refers to communication between servers and systems inside the data centre.

## Redundancy
Redundant links and devices help maintain service continuity during failures.

## VXLAN Basics
VXLAN helps extend Layer 2 networks over Layer 3 infrastructure and supports large-scale virtualised environments.

## Common Operational Challenges
- Congestion
- Misconfiguration
- Loop prevention
- Latency issues
- Hardware failures
