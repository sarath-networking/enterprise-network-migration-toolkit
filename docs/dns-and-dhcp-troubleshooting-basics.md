# DNS and DHCP Troubleshooting Basics

## DNS Basics
DNS converts domain names into IP addresses to allow devices to locate services and websites.

## Common DNS Issues
- DNS server unreachable
- Slow DNS response
- Incorrect DNS records
- Cached outdated records
- DNS forwarding problems

## DHCP Basics
DHCP automatically assigns IP addresses and network settings to devices.

## Common DHCP Issues
- IP conflicts
- DHCP scope exhaustion
- Incorrect gateway assignment
- VLAN configuration issues
- DHCP server unavailable

## Basic Troubleshooting Steps
- Check IP configuration
- Verify DNS server reachability
- Test gateway connectivity
- Use ping and nslookup tools
- Review logs and alerts

## Good Practices
- Monitor services regularly
- Document recurring issues
- Maintain backup configurations
- Validate changes carefully
