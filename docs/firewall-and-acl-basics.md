# Firewall and ACL Basics

## What is a Firewall?
A firewall helps control and secure network traffic based on security rules.

## Common Firewall Functions
- Traffic filtering
- Access control
- Threat prevention
- VPN support
- Network segmentation

## ACL Basics
ACL (Access Control List) rules are used to permit or deny traffic based on IP addresses, ports, or protocols.

## Inbound vs Outbound Rules
- Inbound rules control incoming traffic
- Outbound rules control outgoing traffic

## Enterprise Use Cases
- Restrict unauthorized access
- Protect servers and applications
- Separate network zones
- Secure remote access

## Common Operational Issues
- Incorrect ACL rules
- Blocked legitimate traffic
- Misconfigured firewall policies
- Logging and monitoring gaps
