# MPLS Basics and Use Cases

## What is MPLS?
MPLS (Multi-Protocol Label Switching) is a forwarding technology widely used in ISP and enterprise networks.

## Benefits of MPLS
- Efficient traffic forwarding
- Better scalability
- Traffic engineering support
- Enterprise VPN services

## Key Components
- LER (Label Edge Router)
- LSR (Label Switch Router)
- MPLS Labels

## How MPLS Works
Packets are forwarded using labels instead of full IP lookups, improving efficiency within large networks.

## Common Use Cases
- Enterprise WAN connectivity
- ISP backbone networks
- MPLS VPN services
- Traffic prioritisation

## Common Operational Issues
- Label distribution problems
- Routing mismatches
- Connectivity instability
- Latency and congestion
