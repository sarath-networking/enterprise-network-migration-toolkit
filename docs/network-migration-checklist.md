# Network Migration Checklist

## Pre-Migration
- Backup existing device configurations
- Verify IP addressing and VLAN details
- Check routing and connectivity status
- Inform affected teams and users
- Prepare rollback plan

## During Migration
- Apply configurations carefully
- Verify routing protocols and neighbour status
- Monitor traffic and latency
- Check firewall and ACL behaviour
- Validate DNS and internet connectivity

## Post-Migration
- Test failover and redundancy
- Monitor logs and alerts
- Verify customer connectivity
- Document issues and resolutions
- Update network documentation
