# Network Monitoring and Alerting Basics

## Why Monitoring is Important
Network monitoring helps detect issues early and maintain service stability within operational environments.

## Common Monitoring Areas
- Interface utilisation
- CPU and memory usage
- Latency and packet loss
- Routing neighbour stability
- Hardware health

## Common Monitoring Tools
- SolarWinds
- PRTG
- Splunk
- Wireshark
- SNMP monitoring tools

## Alerting Basics
Alerts notify operational teams when thresholds or abnormal behaviour are detected.

## Benefits of Monitoring and Alerting
- Faster incident response
- Reduced downtime
- Better troubleshooting
- Improved operational visibility
- Early issue detection

## Good Practices
- Configure useful alert thresholds
- Review logs regularly
- Monitor critical infrastructure continuously
- Document recurring issues
