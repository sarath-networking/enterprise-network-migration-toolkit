# Network Monitoring Basics

## Key Areas to Monitor
- Interface status
- Bandwidth usage
- Latency and packet loss
- CPU and memory utilisation
- Routing neighbour status

## Monitoring Tools
- SolarWinds
- Wireshark
- PRTG
- SNMP monitoring

## Common Issues
- High latency
- Packet drops
- Interface errors
- Routing instability
- DNS resolution failures

## Good Practices
- Monitor proactively
- Configure alerts
- Document recurring issues
- Validate changes carefully
- Review logs regularly
