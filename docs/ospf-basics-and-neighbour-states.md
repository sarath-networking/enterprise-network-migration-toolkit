# OSPF Basics and Neighbour States

## What is OSPF?
OSPF (Open Shortest Path First) is a dynamic routing protocol used in enterprise and service provider networks.

## Benefits of OSPF
- Fast convergence
- Scalable routing
- Efficient route updates
- Support for large networks

## Common OSPF Neighbour States
- Down
- Init
- 2-Way
- ExStart
- Exchange
- Loading
- Full

## DR and BDR
Designated Router (DR) and Backup Designated Router (BDR) help reduce unnecessary routing update traffic in multi-access networks.

## OSPF Areas
- Area 0 is the backbone area
- Areas improve scalability and reduce routing overhead

## Common Troubleshooting Checks
- Area mismatch
- Authentication mismatch
- Interface status
- MTU mismatch
- Neighbour adjacency issues
