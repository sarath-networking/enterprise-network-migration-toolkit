# VLAN and STP Basics

## What is a VLAN?
A VLAN (Virtual Local Area Network) is used to logically separate devices within the same physical network infrastructure.

## Benefits of VLANs
- Better security
- Reduced broadcast traffic
- Improved performance
- Easier network management

## Broadcast Domains
Each VLAN creates a separate broadcast domain which helps reduce unnecessary network traffic.

## What is STP?
STP (Spanning Tree Protocol) helps prevent Layer 2 switching loops in networks with redundant links.

## Why STP is Important
- Prevents broadcast storms
- Improves network stability
- Supports redundancy and failover

## Access and Trunk Ports
- Access ports carry traffic for a single VLAN
- Trunk ports carry traffic for multiple VLANs

## Common Troubleshooting
- VLAN mismatch
- Trunk configuration issues
- STP blocked ports
- Loop-related instability
