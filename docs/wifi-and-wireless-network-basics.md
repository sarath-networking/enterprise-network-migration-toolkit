# Wi-Fi and Wireless Network Basics

## What is Wi-Fi?
Wi-Fi allows devices to connect to networks wirelessly using radio frequencies.

## Common Wi-Fi Components
- Access Points (APs)
- Wireless Controllers
- SSIDs
- Client Devices

## 2.4 GHz vs 5 GHz
2.4 GHz:
- Longer range
- More interference

5 GHz:
- Faster speeds
- Better performance
- Shorter range

## Roaming
Roaming allows wireless devices to move between access points while maintaining connectivity.

## Common Enterprise Wi-Fi Issues
- Weak signal strength
- Interference
- Congestion
- Authentication failures
- Roaming instability

## Good Practices
- Proper AP placement
- Channel planning
- Signal monitoring
- Secure authentication
